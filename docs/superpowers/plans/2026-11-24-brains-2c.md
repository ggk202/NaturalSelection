# Brains 2c Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Spec:** `docs/superpowers/specs/2026-11-24-brains-2c-design.md`

**Global Constraints:** deterministic; roundtrip identical; schema 5; suites green.

**Review Focus:**
- Calls from creatures that died this step are still heard next step. That's accepted (sound outlives the caller); test it doesn't crash.
- Hearing across the world wrap.
- Meaning detection with tiny samples must not fire (≥50 calls).
- Kin of the creature itself must be excluded.
- The overlay must keep working after the world changes or the creature dies.

### Task 1: Kin and intelligence
- **Produces:**
  - `relatedness(a, b)` in `genome.js`
  - `intelligence(brain)` in `neat.js`
  - input `kinNear` (from vision: the creature with the strongest ray signal)
- **Tests:** self = 1, strangers ≈ 0; intelligence grows with structure, lr and map reading; kinNear is high for a clone in view.

### Task 2: Voice and hearing
- **Produces:**
  - outputs `call`, `syllA`, `syllB`
  - inputs `hear0..hear3`, `hearSin`, `hearCos`, `hearKin`
  - `world.calls` (previous step) and `world.newCalls`
  - call cost
- **Tests:**
  - a forced caller is heard by a near creature on the next step, with the right syllable and direction
  - not heard out of range
  - antennae extend range
  - calling costs energy
  - heard across the wrap
  - roundtrip continues identically

### Task 3: Meaning detection
- **Produces:**
  - `tracker.noteCall(c, syll, ctx)` and `tracker.noteContext(c, ctx)` (base rates)
  - meanings evaluated at each species update → `first` checkpoints such as "Species N evolved an alarm call (ka)"
  - species gain a `lexicon`
- **Tests:** a synthetic alarm pattern fires once; fewer than 50 calls never fires; a context at base rate doesn't fire.

### Task 4: Viewer
- 3D memory overlay toggled from the inspector (one InstancedMesh of quads, rebuilt every 0.5 s).
- Call rings (an InstancedMesh with ring geometry; each lasts 1 s and grows with loudness).
- Inspector rows for intelligence, kin, heard and said, plus the species lexicon.
- Signals tab in the charts, using a `calls` count per syllable in the stats samples.
- Intelligence added to the Traits series.
- **e2e:** overlay toggle adds the mesh; Signals tab draws; no errors.

### Task 5: Measure, review, push
Slow suites, a capability check, a quick count of species with detected meanings in 30-minute runs, then a final review.
