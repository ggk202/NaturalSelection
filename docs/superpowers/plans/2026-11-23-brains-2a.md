# Brains 2a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the fixed MLP with evolvable recurrent brains (NEAT-style, asexual) fed by vision rays that forest cover can block, and detect ambushes.

**Architecture:**
- `src/sim/neat.js`: genome operations and network evaluation, pure.
- `src/sim/vision.js`: ray perception, pure, given world accessors.
- `World` keeps per-creature activation state, builds inputs from rays plus scalars, and charges brain upkeep.
- Species distance and serialization learn the new genome.
- The inspector draws the variable network.

**Tech Stack:** As before.

**Spec:** `docs/superpowers/specs/2026-11-23-brains-2a-design.md`

## Global Constraints
- Deterministic per seed. Serialize roundtrip continues identically. `SCHEMA_VERSION = 3`.
- No scripted behaviour. Founders are minimal and random.
- Brain upkeep: 0.002 per hidden neuron + 0.0004 per enabled connection.
- The `maxRays` setting (default 9) caps rays. Rays = `min(maxRays, 1 + 2*eyes)`.
- 2a must reach ≥80% of baseline food per creature-minute (`bench/baseline-v2-mlp.json`).

## Review Focus
1. **Mutation removes a neuron that connections point to:** no dangling ids and no NaN. Test: T1 `remove neuron drops its connections`.
2. **Recurrent self-loops and cycles:** activations stay bounded over 10k steps. Test: T1 `activations stay bounded`.
3. **Creature with 0 eyes:** 1 ray, no crash, and the input vector stays the full length. Test: T2 `zero-eye creature`.
4. **Ray across the world wrap:** objects across the torus edge are seen. Test: T2 `sees across wrap`.
5. **Clone/mutate in god-mode, and a mid-run save/load:** activation state is preserved, or reset consistently. Test: T3 `roundtrip continues identically`.

### Task 1: NEAT genome and network (`src/sim/neat.js`, `test/neat.test.js`)
**Produces:**
- `INPUT_COUNT(maxRays)`, `OUTPUTS` (turn, throttle, attack, reproduce)
- `createBrain(rng, nIn, nOut, links = 6) -> Brain {nodes:[{id,type:'in'|'hid'|'out',bias,tau}], conns:[{from,to,w,on}]}`. Inputs have ids 0..nIn-1 and outputs nIn..nIn+nOut-1.
- `mutateBrain(b, rate, rng, nextNodeId: () => int) -> Brain` (new object)
- `brainDistance(a, b) -> number`, `cloneBrain`, `brainCost(b) -> energy/s`
- `newState(b) -> Float32Array` (activation per node index)
- `runBrain(b, state, inputs, out) -> out`. It is compiled lazily and cached in a WeakMap keyed by brain: node index map plus incoming lists.
- [ ] Tests:
  - `founders are minimal` (no hidden neurons, 4–8 connections)
  - `zero conns gives neutral output`
  - `add neuron splits a connection and keeps the output near-identical`
  - `remove neuron drops its connections`
  - `activations stay bounded` (random dense recurrent brain, 10k steps, all |a| ≤ 1)
  - `memory: a self-loop holds a pulse` (a slow-tau hidden neuron holds activation for >10 steps after the input is removed)
  - `distance zero to self and positive to mutant`
  - `cost grows with structure`
  - `mutate is deterministic`
- [ ] FAIL → implement → PASS → commit `feat: NEAT-style recurrent brains`.

### Task 2: Vision rays (`src/sim/vision.js`, `test/vision.test.js`)
**Produces:** `castRays(world, c, rays: int, out: Float32Array, offset: int)`. It writes 3 channels per ray (food, creature ±, obstacle) for `world.settings.maxRays` rays and zero-fills unused ones. Rays spread evenly over the fov (one ray points straight ahead). Intensity = `1 - d/range`. Forest cover is applied per ray as specified.
- [ ] Tests:
  - `food straight ahead lights the centre ray`
  - `prey positive, threat negative`
  - `forest hides at distance but not up close`
  - `water is an obstacle for non-swimmers only`
  - `zero-eye creature`
  - `sees across wrap`
- [ ] FAIL → implement → PASS → commit `feat: vision rays with forest occlusion`.

### Task 3: World integration
**Files:** `world.js`, `genome.js`, `species.js` (via `genomeDistance`), `serialize.js`, `brain.js` (replaced by neat.js; delete it), `test/helpers.js`, the affected tests, `src/ui/inspector.js` (temporary: keep it working).
- `genome.brain` becomes a Brain.
- `c.brainState` is created at spawn (newState) and reset on mutateCreature.
- Inputs = rays ++ scalars (energy, temperature, tempGradient, biomeFood, biomeDanger, cover, slopeAhead, waterAhead, hazardDist, bias). `world.sense(c, out)` keeps its name.
- Upkeep adds `brainCost`.
- Mutation uses `world.nextNodeId`, which is serialized.
- **Test helpers:** `genome(body, biases)` builds a brain with no connections whose output biases force the outputs. Existing behaviour tests keep their intent.
- `c.threatNear` and the fled counter come from the creature ray channel (any negative < −0.3).
- [ ] Tests:
  - every existing suite passes after the helper and fixture updates
  - new: `roundtrip continues identically` with the new brains
  - `brain upkeep charged`
  - `children inherit and mutate brains`
- [ ] Commit `feat: world runs evolvable brains with vision`.

### Task 4: Ambush detection
**Files:** `behavior.js`, `world.js`, `species.js`, tests.
- Counters gain `stillRun` (consecutive steps with throttle < 0.1) and `ambushes`. An attack within 40 steps of ending a still run of ≥60 steps counts as an ambush.
- Label `ambusher` when the window holds ≥1 ambush; it ranks above hunter.
- Species checkpoint `first` "Species N: first ambush" (once per species, plus a global "First ambush").
- [ ] Tests: `wait then strike counts as ambush`; `label ambusher`; `first ambush checkpoint`. Commit.

### Task 5: Brain graph in the inspector
**Files:** `src/ui/inspector.js`, e2e check.
- Layered layout: depth = longest feed-forward path from the inputs (ignoring back-edges).
- Rays are shown as one compact row.
- Edges are coloured by sign and their width shows the weight. Recurrent edges are curved.
- Node fill shows the current activation.
- [ ] e2e: `tap inspects creature` asserts no errors with the new brains. Screenshot check. Commit.
