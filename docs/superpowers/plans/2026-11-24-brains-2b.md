# Brains 2b Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Mental maps, map senses, reward-modulated Hebbian learning, inherited maps, homebody/patroller labels.

**Spec:** `docs/superpowers/specs/2026-11-24-brains-2b-design.md`

**Global Constraints:** deterministic; roundtrip identical; schema 4; all existing suites stay green.

**Review Focus:**
- Map indexing across the world wrap and non-multiple world sizes.
- Hebbian updates hitting NaN or running away (weights clamp to ±4).
- Save size and roundtrip with maps and weights.
- God-mode clone and mutate reset learned weights and maps consistently.
- Newborns with no parent (founders, respawns) get empty maps.

### Task 1: `src/sim/memory.js`
- **Produces:** `createMap(W, cell)`, which returns `{ n, cell, food: Int8Array, danger: Int8Array, visits: Int8Array }`.
- **Functions:**
  - `mapIndex(m, x, z)` (wraps)
  - `remember(m, x, z, channel, amount)` (saturating)
  - `recall(m, x, z, channel) -> [-1,1]`
  - `fade(m)` (×0.95, truncating)
  - `inheritMap(m)` (copy ×0.5)
  - `encodeMap` / `decodeMap` (base64)
- **Tests:** wrap indexing, saturation, fade to zero, inherit halves, encode roundtrip.

### Task 2: Learning in `neat.js`
- **Produces:**
  - brains gain `lr` and per-connection `p`; `createBrain` and `mutateBrain` handle them, with jitter
  - `initWeights(b) -> Float32Array` (working weights per connection index)
  - `runBrain(b, state, inputs, out, weights?)` uses the working weights when given
  - `learn(b, state, prevState, weights, reward)`
- **Tests:**
  - reward strengthens a plastic co-active link and punishment weakens it
  - plasticity 0 never changes a weight
  - weights stay clamped
  - deterministic

### Task 3: World integration
- **Inputs:** N_IN gains 7 map inputs (named `mapFoodAhead`, `mapFoodLeft`, `mapFoodRight`, `mapDangerAhead`, `mapDangerLeft`,
  `mapDangerRight`, `familiarity`).
- **Per creature:** `c.map`, `c.weights`, `c.prevState`.
- **Each step:**
  - the reward is computed from the energy change
  - `learn` runs
  - memories are written on eat (food) and on non-upkeep energy loss (danger)
  - visits are counted
  - maps fade every 5 s
- **Lifecycle:** children inherit the faded map; god-mode clone and mutate reset both.
- **Costs** are added to upkeep.
- **Serialize:** schema 4 with base64 maps and weights.
- **Tests:** steering away from a remembered danger, roundtrip continues identically, inherited map, costs charged.

### Task 4: Labels
homebody and patroller in `behavior.js`, using window start, path and max distance tracked on the creature. Tests, then add them to the charts.

### Task 5: Measure
Run the slow suites. If specialization now passes, promote it from todo; otherwise record the numbers. Commit and push.
